## 三次仪器测量：B 那条线到底站不站得住

| 文件 | 问的是 | 答案 |
| --- | --- | --- |
| `B-reproducibility-2026-08-06.json` | 同一批对重判三遍会飘多少 | **0.0034**。但**判词飘**：未胜出 / 赢 / 赢——门槛 0.5474 落在测量自身 0.5457–0.5491 的散布里 |
| `B-sampling-variance-2026-08-06.json` | 同一模型换采样种子会飘多少 | **0.0032**。顺带：中位字数 49 → 52，**吃掉 A′ 那条线的一半** |
| —— | 那第四轮与第五轮的 0.0228 呢 | **不是仪器抖的**（两项都 0.003 量级），但换一批探针会不会还这样，**答不了**：两轮逐条判词只有 69.7% 相同 |

**这三份都不改任何一轮的判词。** 第五轮 B 按注册的第一遍算，不过。
