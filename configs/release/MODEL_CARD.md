# mindsurf-omni（嫁接体，冻结 Thinker）

一个 **152M** 参数的中文语音对话模型：语音进、语音出，
文本与音频 token 在同一个自回归序列里。

**这张卡只写量过的数字。** 每一条都带噪声底与判定，
判定只有「改善 / 劣化 / 无法区分」三种；分辨不了关心的效应时标成「仅报告」，
不参与判定。协议与逐条证据在
[代码仓库](https://github.com/oscar030406/mindsurf-omni) 的 `docs/experiments/`。

## 结构

| | 参数量 | 来源 |
| --- | ---: | --- |
| Thinker | 89.86M | 我们自己的中文基座 |
| Talker | 47.05M | **上游 MiniMind-o 发布权重** |
| 合计 | 139.08M（整机 152.06M） | |

Talker 只通过 `talker.embed_proj` 读 Thinker 的隐状态——接口窄到可以换半边，
这一版就是**换掉 Talker、只训那座桥**。
音频编解码用 [Mimi](https://huggingface.co/kyutai/mimi)（8 码本，12.5 Hz）。

## 量过的

对上游发布权重 `sft_omni_768`，同一批固定文本、同一个判官、逐样本配对：

| 轴 | 本模型 | 上游 | 判定 |
| --- | ---: | ---: | --- |
| CER | 0.1078 ± 0.0202 | 0.0763 ± 0.0159 | `indistinguishable` |
| UTMOS | 2.4265 ± 0.0457 | 2.4018 | `indistinguishable` |
| 静音率 | 0/160 | 0/160 | 同 |
| 音色克隆余弦（12 音色 × 20 句） | seen 0.6470 / unseen 0.6054 | 0.6186 / 0.5633 | **`improved` (+0.0364, ±0.0335)** |

**首音延迟（独占卡实测）**：TTF-Audio **145.1 ± 4.1 ms**，P95 189 ms。

## 边界：这些是它做不到或没测过的

**回合制，不是全双工。** 「打断」在这里的含义是「取消当前这一轮」，
模型层随时可停；**判断用户是否插话那一半我们没有做**，端点决定在客户端。

**音色只有 6 个认得出。** 12 选 1 的最近邻识别里，
arthur / serena / eric / uncle_fu / dylan / moon 是 19–20/20，
而 cherry / ethan / chelsie / momo ≤ 2/20（塌向 serena 与 moon）。
**别把后四个当独立音色投放。** 完美克隆（参考码回环）是 12/12，
所以这是生成侧带的身份不够，不是判官分不开。

**回复偏长。** 中位朗读约 **30 秒**、占用比 14.5×，
**5 秒时 94% 的回复还没说完**。语音里没有快进，这是已知的产品短板。

**情绪控制没有交付。** 能力在（给一条带情绪的参考，输出韵律会变），
但「不动身份」这个承诺给不出——旋钮 `spk_emb` 同时就是身份。

**多轮只测到三轮**：不崩、上下文利用 82% 且不衰减，
但答得上的比例随深度掉（42% → 24% → 14%）。

**自然度的天花板不在模型。** 与真人的差距里 **79% 是编解码器、21% 是 Talker**，
我们已拿到编解码天花板的 92.2%。
